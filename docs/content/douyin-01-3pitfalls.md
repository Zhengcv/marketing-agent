## 🎤 口播脚本（逐句，直接念）

```
[0-3秒 · 钩子]
（镜头对着自己，表情认真）
"给孩子找家教，你以为最怕的是花钱？不——最怕的是花了钱，孩子还不想学。"

[3-15秒 · 痛点 1]
"第一个坑：只看价格不看资质。
很多家长上来就问'多少钱一节课'——
但价格低≠靠谱，没有资质认证的老师，你敢把孩子交给他吗？"

[15-25秒 · 痛点 2]
"第二个坑：试课只看老师讲得好不好。
一个老师讲得精彩，不代表你孩子愿意跟着学。
正确的做法是——观察孩子试讲后的反应，问一句'你还想跟这个老师学吗'，比什么都重要。"

[25-35秒 · 痛点 3]
"第三个坑：没搞清楚谁付信息费。
有些平台两边收钱，家长付完中介费还要付课时费——
正规的信息撮合平台，信息费是老师单边付的，家长只付课时费。"

[35-45秒 · 引导]
"这三个坑，你踩过几个？评论区告诉我。
我们整理了 XX 城市已认证老师的名单，私信'老师'我发给你。
关注我，帮你找到靠谱的家教老师。"
```

## 📋 拍摄清单

```
□ 手机横屏拍摄（16:9）
□ 光线：正面自然光，不要背光
□ 背景：干净的书桌/书架/白墙，不要太乱
□ 语速：正常偏慢，像在跟朋友聊天
□ 表情：放松自然，不要"播音腔"
□ 服装：干净简洁，不要穿 logo 太大的衣服
□ BGM：轻快纯音乐，音量不超过人声的 30%
□ 字幕：用剪映自动生成，黄色或白色字体 + 黑色描边
```
