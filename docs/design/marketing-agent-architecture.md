# Tutor-Match 社媒自动化引流 Agent · 积木化技术方案

> 产出：5 路 pro 深度拆解 70+ GitHub 仓库 → 组件级合并
> 日期：2026-08-17
> 状态：**待 L1 审批**

---

## 0. 一句话方案

**不抄任何单一仓库，而是拆出 5 块积木（内容生产/质量门/合规闸/发布通道/反检测底座），每块都用「该领域事实标准仓库」的组件，拼成我们自己的半自动营销 agent。**

核心立场：**半自动，不是全自动**。AI 承担 90% 工作（选题→写→配图→合规→填表），最后"点发布"由人做。这不是妥协，是 4 份调研反复验证的结论——纯自动 = 封号 + 违反平台 ToS + 撞 2026 年 AI 托管账号新规。

## 2. 逐积木拆解 + 复用来源 + 实现要点

### 积木① 内容生产层

**复用仓库**：
| 来源 | 星数 | 复用组件 | 价值 |
|---|---|---|---|
| `chnjames/AIGEOTOOLS` | 149 | 20+ 平台内容模板（知乎/小红书/公众号） | 高 |
| `NaufalRizqullah/opensource-clipping` | 63 | AI 剪辑管线（人脸跟踪/卡拉OK字幕/BGM/Hook） | 高 |
| `T0UGH/videoclaw` | 111 | Skill 驱动分镜→图→视频流水线 | 中 |
| `mengke-wang/xiaohongshu-ai-workbench` | 489 | 小红书中文语境 Codex Skills | 中 |

**实现要点**：
- 选题用「家长搜什么写什么」原则（已定 playbook S2 的选题库）
- 文本生成用 DeepSeek（OpenAI-compatible），prompt 内嵌反 AI 规则 + 合规红线
- 视频走「口播脚本 → 剪映/opensource-clipping 剪辑」，**不搞 AI 数字人**（家教重信任，真人出镜或图文更适合）

### 积木② 质量门禁层（质量保证重点）

**复用仓库**：
| 来源 | 星数 | 复用组件 | 价值 |
|---|---|---|---|
| `coreyhaines31/marketingskills` | 44.6k | **七遍扫描** + 专家评审团评分 | 高 |
| `rediumvex/seo-blog-writer-claude` | 45 | 反 AI 6 规则（burstiness/perplexity/三明治法） | 高 |
| `indranilbanerjee/digital-marketing-pro` | 745 | Humanize 门禁 + 校准语料 | 高 |

**七遍扫描**（每遍只查一个维度，查完回环复查前一遍）：
1. Clarity 清晰度 → 2. Voice 品牌一致 → 3. So What 利益连接 → 4. Prove It 证据支撑 → 5. Specificity 具体化 → 6. Emotion 情感唤起 → 7. Zero Risk 零风险

**专家评审团**：3 个人设（转化文案师 / 目标家长视角 / 合规专家）各打 1-10 分，全部 ≥7 且均值 ≥8 才放行，低分项优先改。

**反 AI 6 规则**（让内容不像 AI 写的关键）：
- 混合 3 词短句与 40 词长句（burstiness）
- 每 200 字插一个第一人称经历（E-E-A-T）
- 封杀"在当今社会/值得注意的是"等 AI 填充语
- 列表用 4/6 项，禁 5 项（AI 默认格式）
- hook 和标题手写，AI 只写中段

### 积木③ 合规闸（一票否决，最关键）

**复用仓库**：
| 来源 | 星数 | 复用组件 | 价值 |
|---|---|---|---|
| `sdhack/ecommerce-content-review` | 0 | **教育行业规则组 + 三级审核架构**（已落盘 `/d/tmp/rules.json` 341KB/2104 条） | 高 |
| `houbb/sensitive-word` | 6k | Java DFA 敏感词过滤（本项目 yudao 是 Java，直接依赖） | 高 |

**三级审核架构**：
- **L1 词库匹配**：2104 条规则机械匹配（广告法通用/教育行业/平台专属/品牌自定义）
- **L2 语境降级**：8 维语境自动调整（否定/免责/条件限定/引用 → block 降为 warn），避免误杀"并非国家级产品"
- **L3 Agent 研判**：结合法规知识库，跑 9 项隐含风险（谐音/拼音缩写/表情符号/双关），可 override L1/L2

**教育行业核心违禁词**（已落盘，节选）：
- 绝对化：国家级/最高级/第一/唯一/顶级/100%
- 承诺性：包过/保过/提分/保送/升学率/不过退款
- 命题关联：命题人/押题/内部题库/原题泄露
- 资质造假：清北名师/状元名师/在职教师（需证明真实）
- 引流词（小红书限流）：加微信/私信/二维码

### 积木④ 发布通道层（半自动）

**复用仓库**：
| 平台 | 来源 | 星数 | 复用组件 | 价值 |
|---|---|---|---|---|
| 小红书 | `xpzouying/xiaohongshu-mcp` | 15.3k | MCP 发布协议 + 一年未封的浏览器通道 | 高 |
| 小红书备选 | `white0dew/XiaohongshuSkills` | 3.3k | CDP 免驱动引擎 + 选择器中心化 | 高 |
| 抖音 | `dreammis/social-auto-upload` | 14.3k | 8 平台上传器 + 抖音最稳流程 | 高 |
| 抖音备选 | `dorisoy/ShortVideo.AutoPublisher` | 166 | MCP 包装 + 队列调度 + Polly 重试 | 中 |

**半自动流程**：
```
1. 登录态初始化（一次性）：扫码 → storageState 落盘 → 复用 Chrome 会话
2. 每次发布：
   AI 生成内容 → 质量门 → 合规闸 → 填入发布表单（标题/正文/图/标签/定时）
   → 生成预览 → 【人工点发布】→ 回写结果到日志
```

**安全节奏红线**（4 份调研共识，硬约束）：
- 每天 ≤1 篇/账号，间隔 24h+
- 自动化内容占比 <30%
- 加「AI 辅助创作」声明 + AI 水印（2026 新规）
- 发布后访问管理页确认（三重校验）

### 积木⑤ 反检测底座（地基）

**复用仓库**：
| 来源 | 星数 | 复用组件 | 价值 |
|---|---|---|---|
| `CloakHQ/CloakBrowser` | 30k | 源码级 71 个 C++ 补丁，reCAPTCHA 0.9 人级 | 高（首选） |
| `feder-cr/invisible_playwright` | 1.9k | 开源替代（Firefox 系，贝叶斯指纹） | 高（纯开源） |
| `Kaliiiiiiiiii-Vinyzu/patchright` | 4.1k | 开源替代（Chromium 系） | 中 |
| `g1879/DrissionPage` | 12.4k | 复用已登录 Chrome（中文平台标配） | 高 |

**选型决策**：
- **首选 CloakBrowser**（生产），**开源替代 invisible_playwright/patchright**（避免订阅锁）
- **关键**：架构上把「引擎可热替换」设计进去——反检测是军备竞赛，不能绑死单一引擎

**反检测四件套**（缺一不可）：
1. 源码级指纹伪装（CloakBrowser）
2. 住宅代理（粘性 IP，时区/语言/geo 联动）
3. humanize 真人行为（贝塞尔鼠标/逐字键盘/随机停留）
4. Cookie 持久化（storageState，复用登录态，永不重放登录）

## 5. 分阶段落地计划

| 阶段 | 内容 | 产出 | 验收 |
|---|---|---|---|
| **P0 合规闸（先做）** | 落盘 rules.json → 三级审核脚本 | `compliance/` 可用 | 喂 10 条测试文案，违禁词全拦，否定语境不误杀 |
| **P1 内容生产+质量门** | prompt 模板库 + 七遍扫描 + 反 AI | `content/` + `quality/` 可用 | 生成 10 条小红书文案，专家评审团均值 ≥8 |
| **P2 反检测底座** | CloakBrowser 或 invisible_playwright 引擎 | `browser/` 可用 | 登录小红书/抖音不触发验证码 |
| **P3 发布通道** | xiaohongshu-mcp + social-auto-upload 接入 | `publish/` 可用 | 半自动发 1 条小红书 + 1 条抖音，人工点发布成功 |
| **P4 串起来** | 5 积木串成流水线 + 调度 + 频控 | 全链路可用 | 端到端跑通：选题→写→审→合规→发→回写 |

**优先级依据**：合规闸 P0 先做——因为它是我们项目的差异化壁垒（4 份调研确认「没有中文教育行业 + 多平台合规全栈开源方案」），且涨价的窗口期先抢「最难被别人替代」的部分。

## 6. 风险与红线（必须写进实现）

1. **封号风险**：纯 API 签名发布（ReaJason/xhs、Spider_XHS）会触发验证码+签名失效，**禁用**。只用浏览器自动化。
2. **许可红线**：
   - `DrissionPage` 商业使用需授权（法律项）
   - `trawl`/`HeadlessX` 是 AGPL（改代码做网络服务必须开源，商用慎用）
   - `CloakBrowser` v148+ 二进制需订阅，免费版 v146 会老化
3. **平台新规**：2026 年已打击 AI 托管运营账号，必须加「AI 辅助创作」声明 + 水印。
4. **合规一票否决**：教育行业违禁词（提分/保过/名师）任何一条命中即 block，这是平台生死线。
5. **引擎可热替换**：反检测是军备竞赛，架构上不能绑死 CloakBrowser。
