# S1 老师侧定向招募 · 操作手册

**策略**：定向邀约本地已认证老师入驻，L2/L3 资质切入，认证即背书
**阶段**：冷启动(0-1 月) | **预算**：¥0 | **KPI**：首月 50 名已认证老师（L2+ 占 30%）

---

## 一、目标画像

| 维度 | 冷启动优先 | 后续扩展 |
|---|---|---|
| **资质** | L2(学历认证) + L3(教资认证) | L1 基础认证 |
| **城市** | 首批 1-2 个城市（选老师密度高的） | 按池扩张 |
| **科目** | 数学/英语/语文 主科 | 物理/化学/全科 |
| **来源** | 现有老师社群 / 本地教育论坛 / 学信网可查 | 转介绍 |

---

## 二、渠道清单（按优先级）

### 渠道 1：现有老师社群渗透（最高效）
**来源**：`Gingiris/gingiris-opensource`(246⭐) 微信群渗透策略

**搜群方法**：
```
关键词搜索：所在城市 + 家教老师群 / 一对一老师群 / 兼职老师群
平台：微信搜索、QQ 群搜索、豆瓣同城小组、贴吧本地吧
目标：找到 10 个活跃老师群（每个 200+ 人）
```

**入群话术**（3 段式，禁止一上来就发广告）：
```
【第 1 天 · 破冰】
"大家好，我是本地做教育信息撮合的，看到群里有不少有经验的老师，想请教一下——大家觉得现在找学生最头疼的是什么？"
→ 目的：引发讨论，了解真实痛点（而不是推销）

【第 2-3 天 · 提供价值】
在群里日常分享：家长找老师的常见问题 / 试课怎么准备 / 如何展示自己的教学履历
→ 目的：建立专业形象，不推销只帮助

【第 4-5 天 · 自然引出】
"最近帮几位家长对接老师，发现很多老师其实资质很好家长却看不到。我们做了个小工具，老师认证后直接展示给家长，有需要的可以看看→[链接]"
→ 目的：自然转化，不硬塞
```

### 渠道 2：本地教育论坛/平台
- **知乎**：搜"XX 城市 + 家教"相关的回答，在评论区以"经验分享"切入
- **小红书**：搜"XX 家教老师"，用个人号留言互动，引导到微信
- **豆瓣同城**：教育类小组发"本地老师资质展示"帖
- **V2EX / 即刻**：在读大学生/研究生老师聚集地

### 渠道 3：老师转介绍（雪球）
- 入驻老师邀请 3 位同行→获信息费折扣（首批用）
- 话术："您身边肯定也有靠谱的老师，推荐入驻我们帮您一起验证"

## 三、认证转化流程（从接触到入驻）

| 步骤 | 动作 | 话术/工具 | 耗时 |
|---|---|---|---|
| 1. 触达 | 上文渠道触达老师 | 渠道话术模板 | 1-3 天 |
| 2. 引导 | 发微信，发"老师入驻指南" | 见下方模板 | 1 天 |
| 3. 注册 | 老师扫码/链接注册，提交资质 | 平台注册页 | 当天 |
| 4. 认证 | 后台审核 L1→L2→L3 | 人工审核 | 1-2 天 |
| 5. 激活 | 认证通过后拉入"已认证老师群" | 私域沉淀 | 当天 |

**「老师入驻指南」微信模板**（复制即用）：

```
老师您好！

我们是[城市名]本地的一个信息撮合平台，专门帮老师和家长对接。

您入驻后我们会：
1. 帮您做实名+学历+教资认证（家长看到认证更信任）
2. 把您的资料展示给有需求的本地家长
3. 家长发需求→您选合适的抢单，不强制接单

入驻只需要：
- 实名信息（L1）
- 学历证书照片（L2，可选但推荐）
- 教师资格证（L3，可选但推荐）

首批入驻的老师信息费有优惠，先到先得。

[入驻链接]
```

## 四、验收标准（30 天节点）

| 指标 | 目标 | 不达标处理 |
|---|---|---|
| 触达老师数 | ≥200 人 | 加渠道，换话术 A/B |
| 注册率 | ≥25%（50/200） | 优化入驻指南/缩短注册流程 |
| 认证完成率 | ≥80%（40/50） | 审核加速，一对一跟进 |
| L2+ 占比 | ≥30% | 定向邀约 L2/L3 而非泛群 |
| 激活率 | 100%（认证通过即拉群） | 检查拉群流程 |

**验证门**：50 名认证老师达标 → 解锁阶段 2（需求侧+S5 KOL）
