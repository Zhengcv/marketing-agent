# S2 内容营销/答疑引流 · 操作手册

**策略**：长尾"怎么找靠谱家教"答疑内容，知乎/小红书/本地号分发，认知承接引流
**阶段**：冷启动(0-1 月) 启动，持续运营 | **预算**：¥0 | **KPI**：3 篇内容单篇触达 1000+

---

## 一、内容矩阵设计

### 选题原则（三条铁律）

1. **搜什么写什么**：不写"我们平台多好"，写家长搜的问题
2. **答疑≠授课**：用"教家长如何判断/选择"，不用"教孩子怎么学"
3. **合规勒紧**：每篇发前自查——有没有"提分/保过/名师/升学率"？有即删

## 二、内容生产 SOP（每篇 2 小时）

### 第 1 小时：写

```markdown
## 每篇结构（固定模板）

1. 开头（50 字）：一句话戳痛点
   ✗ "我们平台有好多老师"
   ✓ "给孩子找家教，最怕的就是花了钱还碰上个不靠谱的老师"

2. 正文（800-1200 字）：3-5 个要点，每点一个小标题
   - 用"家长视角"写，不用"平台视角"
   - 每点后面加一个"家长自查清单"（行动导向）

3. 结尾（50 字）：自然引导
   ✗ "快来我们平台注册"
   ✓ "我们整理了 XX 城市已认证老师的名单，需要的家长可以私信我领取"

4. 评论区 hook（3 条，发完自己先评论）：
   - "你家孩子找家教时最看重老师什么？"
   - "我们城市有已经认证的老师名单，需要的扣1"
   - "还有哪些问题想问的？评论区告诉我，下期写"
```

### 第 2 小时：分发

| 平台 | 动作 | 频率 |
|---|---|---|
| 知乎 | 发文章 + 关联 3 个相关问题贴回答 | 每篇 |
| 小红书 | 发图文笔记（Canva 做封面）+ 3 个标签 | 每篇 |
| 本地公众号 | 投稿/合作号转发 | 每 2 篇 |
| 朋友圈 | 提炼 3 条金句发 | 每天 1 条 |
| 已入驻老师群 | 转发给老师，"可以发给你的家长看" | 每篇 |

## 三、合规自查清单（每篇发前必查）

| 检查项 | 违规词（禁止） | 替代词（允许） |
|---|---|---|
| 成绩承诺 | 提分/涨分/保过/冲刺/升学 | 帮助理解/巩固基础/学习方法 |
| 名师标签 | 名师/金牌/王牌/一线 | 有经验/认证/靠谱 |
| 教学成果 | 多少分/考上了/录取 | 家长反馈/学生评价 |
| 机构关联 | 培训/补课/开班 | 信息撮合/对接/匹配 |
| 平台身份 | 教育平台/培训机构 | 信息中介/撮合平台 |

## 四、验收标准

| 指标 | 30 天目标 | 测法 |
|---|---|---|
| 内容产出 | 10 篇 | 周报计数 |
| 单篇触达 | 3 篇 ≥1000 阅读 | 平台后台数据 |
| 私域转化 | 内容→微信好友 ≥100 人 | 微信新增数 |
| 搜索覆盖 | 3 个关键词在搜索结果前 3 页 | 无痕窗口搜关键词 |
| 合规 | 0 篇踩红线 | 每篇发前自查 + 发后抽查 |

**不达标优先查**：标题是否搜得到？封面是否吸引？正文是否"家长视角"而非"平台推销"？
