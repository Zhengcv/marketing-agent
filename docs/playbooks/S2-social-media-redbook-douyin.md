## 一、小红书 vs 抖音 vs 视频号 三平台差异

| 维度 | 小红书 | 抖音 | 微信视频号 |
|---|---|---|---|
| 用户画像 | 25-40 岁女性，关注育儿/教育 | 泛人群，下沉强 | 中老年+熟人社交 |
| 内容形态 | 图文为主，短视频为辅 | 短视频 | 短视频+直播 |
| 决策心智 | "种草→搜→比→买"，搜索流量大 | "刷到→冲动→转化"，算法推荐 | "朋友分享→信任→转化" |

## 二、小红书运营全流程

### 2.1 账号设置（30 分钟，一次性）

```
头像：不要用 logo，用一张"教育场景"图（如书桌/课本/老师背影）
昵称：[城市] + 教育关键词，如"北京家长帮找老师"
简介：
  为家长提供本地已认证（实名+学历+教资）老师的对接 ✨
  老师信息费透明，家长免费 👇
  已认证老师名单→私信"老师名单"领取

背景图：认证流程图示（L1→L2→L3 三档）
```

### 2.2 内容日历（每日 1 篇，7 天循环）

| 周几 | 内容类型 | 标题模板 | 目的 |
|---|---|---|---|
| 周一 | 本地信息 | "[城市]本周已认证老师名单更新（附资质）" | 直接引流 |
| 周二 | 干货清单 | "给孩子找家教前，家长必问的 5 个问题" | 搜索获客 |
| 周三 | 避坑指南 | "我帮 50 个家长找老师，总结出这 3 个坑" | 建立信任 |
| 周四 | 故事/案例 | "一位妈妈从被骗到找到靠谱老师的经历" | 情感共鸣 |
| 周五 | 互动/提问 | "你家孩子找老师，最看重什么？（投票）" | 互动涨粉 |
| 周六 | 认证科普 | "L2 学历认证和 L3 教资认证有什么区别？" | 教育市场 |
| 周日 | 干货合集 | "这周家长问得最多的 3 个问题（附答案）" | 复利传播 |

### 2.3 每篇内容生产 SOP（30 分钟/篇）

**用 AI 工具链加速**（来源：`mengke-wang/xiaohongshu-ai-workbench` 489⭐）：

```
Step 1（5min）：选题
  → 从选题库选 1 个标题，或搜"XX城市 家教"看什么内容火

Step 2（15min）：AI 写初稿
  → 提示词模板：
  "你是一个帮家长找靠谱家教老师的博主。写一篇小红书笔记，主题是[主题]。
   要求：
   1. 用家长视角，不说教
   2. 每段不超过 3 行，带 emoji
   3. 结尾自然引导私信，不说"快来注册"
   4. 禁止出现"提分/保过/名师/升学率"
   5. 3-5 个要点，每个要点配一个自查清单"

Step 3（5min）：人工润色 + 合规自查
  → 对照 S2 合规清单过一遍，改掉所有踩线词

Step 4（5min）：配图
  → Canva 模板做封面（标题大字 + 统一配色）
  → 正文配图 3-5 张（截图/清单/问答卡片）
```

### 2.4 发布策略

| 时间 | 为什么 |
|---|---|
| 周一至周五 12:00-13:00 | 家长午休刷手机 |
| 周一至周五 20:00-22:00 | 孩子睡后家长刷手机 |
| 周末 10:00-11:00 | 周末上午刷育儿内容 |

**发布后 30 分钟**：自己先评论 2 条，引导互动。

```

  ↓

```

**自动回复模板**：
```

[链接]

看完有合适的老师，可以加我微信 [微信号]

```

## 三、抖音同城引流

### 3.1 账号定位

```
头像：真人出镜或教育场景
昵称：[城市]家长帮 | 找靠谱老师
简介：
  帮 XX 城市家长找靠谱家教老师
  老师实名+学历+教资三认证 ✅
  老师信息费透明，家长免费
  私信"老师"获取已认证名单
```

### 3.2 内容形态（短视频 15-60 秒）

| 类型 | 占比 | 内容 | 制作方式 |
|---|---|---|---|
| 口播干货 | 40% | 家长找老师避坑/选老师标准 | 手机自拍 + 字幕 |
| 图文轮播 | 30% | 认证流程/老师名单/资质展示 | Canva 做图 + 卡点音乐 |
| 场景还原 | 20% | 模拟"家长问、平台答"场景 | 对话字幕 + 背景图 |
| 真实反馈 | 10% | 家长真实评价（打码） | 截图 + 配音 |

### 3.3 制作流程（每条约 20 分钟）

**工具链**：
- `YILS-LIN/short-video-factory`（5.1k⭐）— AI 批量剪辑，素材→字幕→配音→导出
- `DuxSec/videoGenerator`（286⭐）— 自动生成配乐+字幕短视频

```
Step 1（5min）：选题 + 写口播脚本
  → 用 AI 写 60 秒口播稿，结构：痛点→方法→引导

Step 2（5min）：录制
  → 手机自拍或 AI 数字人（如 HeyGen/剪映数字人）
  → 语速适中，表情自然，对着镜头像在跟朋友聊天

Step 3（5min）：剪辑
  → 剪映加字幕+背景音乐+标题贴纸
  → 用 short-video-factory 批量处理多条

Step 4（5min）：发布
  → 标题带城市名 + 关键词
  → 挂 #家教 #XX城市 #家长必看
  → 发布时选"同城"定位
```

### 3.4 抖音同城流量技巧

| 技巧 | 操作 |
|---|---|
| **同城定位** | 每条视频发布时打开"同城"定位，选当前城市 |
| **同城话题** | 带 #XX城市 #XX同城 #XX生活 标签 |
| **POI 打卡** | 挂本地地标（学校/商圈/社区） |
| **评论区互动** | 有人问"在哪个城市"→秒回，引导私信 |
| **同城信息流** | 验证内容有效后，投 ¥50/天同城信息流，定向 25-45 岁女性 |

### 3.5 多平台一键分发

用 `leaperone/MultiPost-Extension`（3k⭐ 浏览器扩展）：
- 一条内容同步发布到：小红书 + 抖音 + 视频号 + 快手
- 省去逐个平台上传的重复劳动

## 四、合规红线（短视频特有风险）

| 禁止 | 原因 | 替代 |
|---|---|---|
| 口播说"提分" | 广告法+教育监管 | "帮助孩子理解" |
| 展示学生成绩单 | 隐私+成绩承诺 | 打码+只展示"进步" |
| 说"我们是培训机构" | 被认定学科培训 | "我们是信息中介" |
| 拍老师上课画面 | 被认定组织授课 | 拍平台界面/认证流程 |
| 说"免费试课" | 试课=教学行为 | "家长自主试讲" |
| 挂"XX 教育"蓝 V | 蓝 V 须有办学许可证 | 个人号运营 |

**每篇发前必查**：对照 S2 合规清单，口播稿逐句过。

| 粉丝 | 500 | 1000 |
