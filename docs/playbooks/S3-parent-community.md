# S3 区域家长社群渗透 · 操作手册

**策略**：进本地家长群/同城群，以"答疑"身份提供价值，转化家长进私域
**阶段**：冷启动(0-1 月) | **预算**：¥0 | **KPI**：30 天沉淀 500 家长进私域

---

## 一、社群类型与优先级

| 类型 | 优先级 | 去哪里找 | 转化难度 |
|---|---|---|---|
| 本地家长群（年级群） | ⭐⭐⭐ | 微信搜索"XX 小学 XX 年级群" | 中（需熟人拉） |
| 同城妈妈群 | ⭐⭐⭐ | 小红书/豆瓣同城/微信搜索 | 低（较开放） |
| 小区业主群 | ⭐⭐ | 物业/业主介绍 | 低（高信任） |
| 教育机构群 | ⭐ | 机构建的群，慎入 | 高（易被踢） |
| 兴趣班群 | ⭐⭐ | 钢琴/美术/体育群 | 中 |
| 升学咨询群 | ⭐⭐⭐ | 本地升学公众号建的群 | 中 |

---

## 二、入群与运营 SOP

### 阶段 A：入群（第 1-3 天）

**渠道 1：微信搜索**（最直接）
```
搜索关键词：
- "XX 城市 + 家长群"
- "XX 小学/初中/高中 + 家长"
- "XX 城市 + 妈妈群"
- "XX 区 + 家长交流"
- "XX 年级 + 家长"

入群方式：扫码/加群主拉
```

**渠道 2：熟人拉**
- 已入驻老师拉进自己学生家长群（老师天然信任背书）
- 话术："老师您在的这个群里家长多，可以把我拉进去吗？我平时可以在群里回答家长找老师的问题，不推销"

**渠道 3：小红书/豆瓣引流**
- 搜"XX 城市 + 家长群"，在评论区留言"求拉，同城家长"
- 被动被拉比主动加更自然

### 阶段 B：破冰（入群后 3 天，关键！）

**不要上来就发广告。** 入群后前 3 天只做三件事：

| 天数 | 动作 | 目的 |
|---|---|---|
| Day 1 | 观察群氛围，看谁活跃、谁有权威 | 摸清群结构和规则 |
| Day 2 | 在别人讨论教育话题时，给一条**有信息量的回答** | 建立"懂行"印象 |
| Day 3 | 继续参与讨论，不主动提平台，等别人问"你是做什么的" | 自然引出，不是推销 |

**Day 2 模板话术**（有人问"怎么找家教老师"时自然回复）：
```
"这个问题我研究过，分享一下：

1. 首先看老师有没有资质认证——实名认证是底线，学历认证和教资认证是加分项
2. 试课的时候家长应该自己观察老师的沟通方式，而不是只看讲得好不好
3. 最好通过信息中介平台找，因为平台会做身份核验，比直接找个人安全

我们家最近在整理本地已认证老师名单，整理好了发群里给大家参考"
```

### 阶段 C：转化（入群后 4-7 天，逐步）

**转化路径**：群友 → 微信好友 → 平台注册 → 发布需求

| 节点 | 动作 | 话术 |
|---|---|---|
| 群→好友 | 在群里提供价值后，自然有人加你 | 通过后第一句："你好，有什么需要了解的？" |
| 好友→平台 | 不用立刻推平台，先解决对方问题 | "你可以先看看我们整理的已认证老师名单[链接]，有合适的再聊" |
| 平台→发需求 | 在看到老师名单后引导 | "这些老师都在我们平台，你看中哪个可以直接发需求，老师会来抢单" |

## 三、维护节奏（持续运营）

| 频率 | 动作 | 内容 |
|---|---|---|
| 每天 | 群内冒泡 1 次 | 不推销，回答问题/分享一条教育资讯 |
| 每周 | 发一次"本周已认证老师更新" | 分享新入驻老师名单（不评价，只列资质） |
| 每月 | 整理一次"本月家长常见问题 Top 5" | 答疑合集，自然植入平台信息 |

**红线**：永远不要在群里发"找老师就上我们平台"——这是最快被踢的方式。

---

## 四、私域沉淀后的运营

家长进微信好友后，分三组运营：

| 组别 | 定义 | 运营动作 |
|---|---|---|
| **A 组-已发需求** | 已在平台成功发布需求的家长 | 每 2 周回访一次："老师怎么样？" |
| **B 组-观望中** | 加了微信但没发需求 | 每周发 1 条教育资讯/认证老师名单，不催 |
| **C 组-已成交** | 通过平台找到老师的 | 让其转介绍，话术："您身边肯定也有在找老师的家长" |

## 五、验收标准

| 指标 | 30 天目标 | 测法 |
|---|---|---|
| 入群数 | 20 个群 | 群列表计数 |
| 触达家长数 | 4000+（20 群 × 200 人均） | 群人数累加 |
| 微信好友新增 | 200 人 | 微信通讯录新增 |
| 私域→平台注册 | 50 人（25%） | 平台后台 |
| 注册→发需求 | 20 人（40%） | 平台后台 |
| 被踢出群 | 0 次 | 逐群检查 |

**不达标优先查**：入群方式是否太硬？破冰阶段是否太快？群类型是否选错（全是机构群）？
