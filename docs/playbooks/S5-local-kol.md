# S5 本地教育 KOL 合作 · 操作手册

**策略**：用"信息中介透明"话术邀本地教育类意见领袖做真实体验背书
**阶段**：验证放大(2-3 月) | **预算**：¥0-3000（资源互换为主，现金为辅）| **KPI**：3 个 KOL 背书 → 30 天转化 30 单

---

## 一、KOL 画像（不是科技 KOL，是教育垂类本地）

| 类型 | 平台 | 粉丝量级 | 合作方式 | 优先级 |
|---|---|---|---|---|
| 本地家长博主 | 小红书/抖音 | 1000-5000 粉 | 资源互换 | ⭐⭐⭐ |
| 本地教育号 | 公众号 | 3000-10000 粉 | 投稿/互推 | ⭐⭐⭐ |
| 本地升学咨询号 | 公众号/微信群 | 500-2000 群友 | 群内答疑身份 | ⭐⭐⭐ |
| 本地生活号 | 小红书/抖音 | 5000-20000 粉 | 付费合作 | ⭐⭐（阶段 2 验证后用） |
| 老师群体中的意见领袖 | 微信 | 无公开粉丝，群内权威 | 入驻+背书 | ⭐⭐⭐ |

## 二、触达流程（从搜到签）

### Step 1：搜（1 天）

```
搜索关键词（小红书/抖音/公众号）：
- "XX 城市 + 育儿"
- "XX 城市 + 升学"
- "XX 城市 + 妈妈"
- "XX 城市 + 教育"
- "XX 小学/初中/高中 + 家长"

筛选标准：
- 粉丝 ≥1000（太小没量）
- 最近 30 天有更新（活号）
- 内容类型是教育/育儿（非纯生活）
- 排除：明显是培训机构运营的号（合作会踩合规红线）

目标：找到 20 个候选，按"粉丝量 × 内容垂直度 × 活跃度"排序
```

### Step 2：触（2-3 天）

**模板 1：给家长博主（资源互换型）**

```
博主你好！我是 XX 城市本地做教育信息撮合的。

看到你一直在分享育儿/教育内容，家长粉丝很精准。我们最近在整理本地已认证（实名+学历+教资）的家教老师名单，家长可以免费查看。

想问问你感不感兴趣——我们可以把你的推荐放在名单里，作为[本地靠谱教育信息源]，你那边可以帮家长朋友推荐一下这个名单，纯资源互换，不涉及费用。

你觉得呢？
```

**模板 2：给教育号博主（投稿/互推型）**

```
你好！我是 XX 城市本地教育信息撮合平台的。

我们写了一篇"[城市名]家长找家教老师的 5 个渠道（含避坑指南）"，在本地家长圈反响不错。想问问能不能投稿到你这边？文章里会自然提到我们的平台，但主要内容是家长关心的干货。

如果不方便投稿，互推也可以——你的文章我们帮你在家长群转发，我们的文章你帮转一次。

你看哪种方式方便？
```

**模板 3：给老师群体意见领袖（入驻型）**

```
老师您好！我是 XX 城市本地教育信息撮合平台的。

我们平台专门帮家长和认证老师对接，老师入驻后家长可以看到老师的资质（实名/学历/教资），然后发需求，老师选合适的抢单。

听说您这边认识很多靠谱的老师，想邀请您入驻，同时如果您愿意帮我们推荐给其他老师，首批推荐入驻的老师信息费可以优惠。

您觉得怎么样？
```

### Step 3：签（1-2 天）

合作确认后，发一份**简单合作备忘录**（不是合同，只是确认两边做什么）：

```
【合作备忘】
博主：[名字]
平台：Tutor-Match

博主侧：
- 在 [平台] 发 1 条内容，介绍"本地已认证老师名单"给家长粉丝
- 内容形式：[图文/短视频]，发布时间：[日期]
- 不提"名师/提分/保过"

平台侧：
- 在名单中标注"博主推荐"作为本地教育信息源
- 在家长群转发博主内容作为回馈
- [可选] 提供 ¥[金额] 合作费

双方确认即生效。
```

## 三、内容方向（给 KOL 的选题建议，控话术合规）

| 选题 | 话术方向 | 踩线风险 |
|---|---|---|
| "XX 城市家长怎么找靠谱老师？" | 信息中介+认证体系 | 无 |
| "我帮家长朋友试了 3 个找老师的渠道，结果..." | 真实体验 | 无 |
| "家长问我要老师推荐，我一般怎么选" | 认证标准 | 无 |
| "孩子成绩不好，第一步不是找老师" | 学习方法论 | 无 |
| "本地已认证老师名单，我帮家长朋友整理好了" | 名单分享 | 无 |

**硬约束**：每个选题给 KOL 前，**先过一遍 S2 合规自查清单**（禁"提分/保过/名师/升学率"）。KOL 的文案也要过审再发。

## 四、效果追踪

| 指标 | 每个 KOL 测什么 | 目标 |
|---|---|---|
| 曝光 | 内容阅读/播放量 | ≥2000 |
| 互动 | 点赞+收藏+评论 | ≥50 |
| 引流 | 内容→平台访问 | ≥100 UV |
| 转化 | 访问→发需求 | ≥10 单 |
| CAC | 如有付费，单均获客成本 | ≤ ¥100 |

**归因方式**：每个 KOL 给一个专属链接/二维码，后台区分来源。

---

## 五、风险点与应对

| 风险 | 应对 |
|---|---|
| KOL 发的内容踩合规红线 | 事前给选题方向+话术建议，**发前审稿** |
| KOL 收了钱不发/效果差 | 先资源互换，验证有效再付费 |
| 被认定"与培训机构合作" | 只找个人博主，不找机构号；话术坚持"信息中介" |
| KOL 效果退潮 | 单次合作，不做长期绑定；效果不好就换 |
| 本地 KOL 太少 | 扩到邻近城市，或从 500 粉小博主做起 |

## 六、验收标准

| 指标 | 30 天目标 | 不达标处理 |
|---|---|---|
| 触达 KOL | 20 人 | 加关键词找 |
| 回复率 | ≥30%（6/20） | 优化触达话术 |
| 签约率 | ≥15%（3/20） | 优先资源互换，降付费门槛 |
| 单 KOL 转化 | ≥10 单/KOL | 换 KOL 类型/选题 |
| 总转化 | 30 单 | 3 个 KOL 之和 |
| 合规事故 | 0 次 | 每篇发前审稿 |
