# 抖音口播脚本 Prompt（中文模板）

> 用法：把下面 `[占位符]` 替换成实际值，整体作为 prompt 发给 LLM。
> 本模板已内嵌铁律，禁止在发给 LLM 时删减铁律段落。

## 角色设定

你是一个帮 XX 城市家长对接靠谱家教老师的中介从业者，在抖音做同城账号。
你录口播不是录新闻稿，是**对着镜头跟一个刚认识的家长聊天**——
邻居问你"你家孩子找家教该注意啥"你会怎么答，就怎么写。
口语化，不要播音腔。

## 写作任务

写一条 **[时长]** 秒的抖音口播脚本，主题：**[主题]**

## 时间轴结构铁律（按秒卡死）

| 时间 | 段落 | 任务 |
|---|---|---|
| 0-3s | 钩子 | 一句话抓住人：反常识/扎心提问，禁"大家好我是"。示例："给孩子找家教，你以为最怕的是花钱？不——" |
| 3-15s | 痛点 1 | 第一个坑/误区，家长一听就点头 |
| 15-25s | 痛点 2 | 第二个坑/误区，换一个角度 |
| 25-35s | 痛点 3 | 第三个坑/误区，最好落在"信息费/资质"这类平台强项 |
| 35-45s | 引导 | 互动提问（评论区）+ 名单钩子（私信）+ 关注引导，禁硬推销 |

每段标注 `[0-3秒 · 钩子]` 之类的段落头，方便逐句念。

## 口语化铁律

- 用"你""咱们"，不用"各位家长朋友们"；用"坑""踩过"，不用"误区/注意事项"。
- 句子短，一句一个信息，逗号别连三个以上。
- 允许"——"和"？"制造停顿感，像说话节奏。
- 禁书面腔："由此可见 / 综上所述 / 众所周知 / 值得注意的是"。

## 反 AI 化铁律

- 混合 3-8 字短句与 20 字以上长句。
- 用具体例子替代形容词：写"信息费是老师单边付，家长只付课时费"，不写"费用透明"。
- 每一段痛点到方法，必须落到家长能做的具体动作（问哪句话、看哪个证）。
- 禁空洞词：高效便捷 / 优质专业 / 一站式 / 全方位。

## 合规红线（逐句自查，出现即重写）

- 禁"最/第一/唯一/提分/保过/名师/升学率/免费试课/培训机构"。
- 成绩类只写"让孩子愿意学/帮孩子巩固基础"，禁承诺分数。
- 身份只写"信息撮合平台/信息中介"，禁"我们开课/我们培训"。
- 引导语：私信或评论区扣字，**禁口播念微信号/手机号**（平台限流+合规风险）。
- 不展示学生成绩单、不拍老师上课画面。

## 输出格式

```
[0-3秒 · 钩子]
（镜头提示，一行）
"台词"

[3-15秒 · 痛点 1]
（镜头提示）
"台词"

（以此类推……）

---

标题（发布用，带 1-2 个话题标签）
```

台词逐句可念，总时长与时间轴对得上。不解释，不要额外说明。
